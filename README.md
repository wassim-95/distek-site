# DISTEK DISTRIBUTION — Site provisoire

Page d'attente statique (HTML/CSS/JS) pour https://distek.tn, compatible GitHub Pages.

## Structure
- `index.html` : page unique (CSS et JS intégrés)
- `assets/favicon.svg` : favicon
- `assets/logo.png` : **à ajouter** — logo officiel, non modifié (utilisé aussi pour l'image Open Graph)
- `CNAME` : domaine personnalisé pour GitHub Pages

## Publication
1. Déposer le logo officiel dans `assets/logo.png`.
2. Pousser sur GitHub, puis Settings → Pages → branche `main`, dossier `/ (root)`.
3. Configurer les DNS chez le registrar (manuellement), puis activer « Enforce HTTPS » une fois la validation faite.
