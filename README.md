# DISTEK DISTRIBUTION — Site provisoire

Page d'attente statique (HTML/CSS/JS) pour https://distek.tn, compatible GitHub Pages.

## Structure
- `index.html` : page unique (CSS et JS intégrés)
- `assets/favicon.svg` : favicon
- `assets/logo.png` : logo officiel (marges transparentes rognées, redimensionné, jamais recoloré)
- `assets/og-image.png`, `assets/apple-touch-icon.png` : visuels de partage et icône mobile (logo sur fond blanc)
- `CNAME` : domaine personnalisé pour GitHub Pages

## Publication
1. Pousser sur GitHub, puis Settings → Pages → branche `main`, dossier `/ (root)`.
2. Configurer les DNS chez le registrar (manuellement), puis activer « Enforce HTTPS » une fois la validation faite.
